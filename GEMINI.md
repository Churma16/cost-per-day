# Repository Rules: cost-per-day

## Skill Restrictions

### Do Not Use `delegate` Skill
- **Strict Prohibition**: Never activate or route tasks through the `delegate` skill in this repository.
- **No Automatic Subagent Delegation**: Do not spawn subagents for planning (`plan.md`), implementation (`implement.md`), code review (`review.md`), or git workflows (`git.md`) based on the `delegate` skill rules.
- **Direct Execution**: Perform planning, code modifications, testing, code reviews, and git operations directly in the primary session, maintaining an interactive and agile pair-programming flow.
